# Registre de décisions

Une décision = un fichier. On écrit **au moment où on décide**, pas après.
Format court : contexte, décision, pourquoi, conséquences. Jamais réécrit — si on
change d'avis, on crée une nouvelle décision qui remplace l'ancienne (et on le note).
